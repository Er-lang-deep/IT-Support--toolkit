# IT Support Toolkit

A Windows Batch scripting project designed to simplify basic IT support and troubleshooting tasks.

## Features

* **System Information:** Collects Windows system details.
* **Network Diagnostics:** Displays IP addresses and network configuration.
* **Process Monitoring:** Lists currently running processes.
* **Connectivity Testing:** Tests whether a network address responds to ping requests.
* **Diagnostic Logging:** Saves results to a report with timestamps.

## Technologies Used

* Windows Batch Scripting
* Command Prompt (CMD)
* Built-in Windows diagnostic utilities

## How to Run

1. Download or clone this repository.
2. Locate `itsupport.bat`.
3. Double-click the file to launch the toolkit.
4. Select an option from the menu.
5. Review the generated diagnostic report in the script's working directory.

Alternatively, open Command Prompt, navigate to the project folder, and run the script by entering its filename.

## Learning Outcomes

Through this project, I practised:

* Variables and user input

## Purpose

This project demonstrates practical Windows administration and troubleshooting skills relevant to entry-level IT support.
